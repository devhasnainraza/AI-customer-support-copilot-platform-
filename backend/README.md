# Copilot Support — AI Multi-Agent Customer Support API & Demo

Enterprise-grade multi-agent AI customer support platform powered by **LangGraph cognitive orchestration**, **FastAPI**, **Supabase pgvector**, and **Meta WhatsApp Cloud API**.

## Features
- **LangGraph Multi-Agent Pipeline**: Planner, Vector RAG Search, Sentiment & Urgency, Grounded Synthesizer, Reflection & Guardrails, and Live Escalation Dispatcher.
- **REST & WebSocket API**: Full OpenAPI endpoints available at `/docs`.
- **Real-Time Escalation Queue**: Instant handoff to human support specialists.
